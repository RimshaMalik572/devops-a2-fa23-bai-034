\## Project Description

This project is a personal portfolio website created using HTML and CSS. It introduces the student and describes the four DevOps lab topics: Git, GitHub, Docker, and GitHub Actions.



\## Project Files

\- `index.html` - Portfolio website content.

\- `style.css` - Website styling.

\- `Dockerfile` - Container configuration (to be added).

\- `.github/workflows/ci.yml` - GitHub Actions workflow (to be added).



\## How to Run

Open `index.html` in a web browser.



\## Docker

The website will be packaged into a Docker image using Nginx. Docker build and run instructions will be added during the Docker stage.



\## GitHub Actions

The workflow will check the website, build a Docker image, and push the image to Docker Hub when changes are pushed to the main branch.
